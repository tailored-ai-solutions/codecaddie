# Governance

CodeCaddie is an open-source project maintained by Alex Go (`@alexgo`). The
maintainer has final responsibility for product direction, security decisions,
release publication, repository administration, trademarks, and accepting or
reverting contributions.

All external changes arrive through pull requests reviewed by the code owner.
Protected `main` accepts squash merges only, keeps a linear history, and
requires a DCO `Signed-off-by` trailer on every commit. The branch ruleset
does not require an approving review because the solo maintainer cannot
approve their own pull requests; every change, including the maintainer's,
must pass the same required status checks before it merges. Decisions favor
the local-first trust boundary, deterministic evidence, data portability,
accessibility, and a small dependable product over surface-area growth.

This lightweight model may evolve when sustained contributors need delegated
ownership. Any governance change will be proposed and reviewed in public.
