# Incident and corrective-action index

This index is the durable repository artifact for CodeCaddie incidents and
post-incident corrective actions. It contains content-free operational facts,
never repository source, customer paths, attachments, goal text, prompts,
secrets, or personal data.

Keep a row until every action has repository-verifiable completion evidence.
