# Security policy

## Supported versions

Until a second release exists, only the latest stable release receives
security fixes. After that, the latest stable release and its immediately
preceding patch release receive them. Pre-release and locally built versions
are supported only for reproducing a problem on the current `main` branch.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/tailored-ai-solutions/codecaddie/security/advisories/new).
Do not open a public issue containing exploit details, repository material,
recovery data, private paths, or credentials.

Include the affected version and platform, impact, reproduction steps, and the
least-sensitive evidence needed to validate the issue. We will acknowledge
reports on a best-effort basis, coordinate remediation and disclosure, and
credit reporters who want attribution. CodeCaddie does not promise a response
or remediation SLA.

Never send provider credentials, source code, customer data, private keys,
or certificates.
