# Support

- Check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) for common issues
  first.
- Use [GitHub Issues](https://github.com/tailored-ai-solutions/codecaddie/issues)
  for reproducible bugs and focused feature requests.
- Use [GitHub Discussions](https://github.com/tailored-ai-solutions/codecaddie/discussions)
  for usage questions.
- Use private vulnerability reporting for security issues.

Include the CodeCaddie version, operating system, installed provider name,
expected behavior, actual behavior, and sanitized logs. Do not include source
code, credentials, recovery bundles, customer data, or private local paths.

Community support is best effort and has no guaranteed response time.
